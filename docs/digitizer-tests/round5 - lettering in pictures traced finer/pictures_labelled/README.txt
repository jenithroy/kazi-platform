runNN = the order the tests were run in round 5 (run01 first, run17 last). Run times were not recorded per board, so this is the order the round 5 README gives: run01-run12, then run13-run17 (the second half of the round).

LATEST = the newest version (end of round 5). Look at this one.
BEFORE = the digitizer at the start of round 5.
OLD    = the rules before round 4 (only on the real-picture boards 6 to 12).
DADE   = another company's tool (png2dst.com), shown for comparison only.
INPUT  = the picture that was fed in.

Layout
  Boards 1-5 and 13-17: panels stacked top to bottom, labels in the left margin.
                        The small grey captions inside the picture (fin, r8, dade, ...) are the originals.
  Boards 6-8:           four panels stacked top to bottom.
  Boards 9-12:          four panels SIDE BY SIDE, left to right (LATEST is the right-hand one).

cer = the share of letters a text reader got wrong (lower is better).
