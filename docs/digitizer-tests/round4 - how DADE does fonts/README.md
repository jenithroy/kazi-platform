# Round 4: DADE and our lettering (2026-11-15): which folder is which

| Folder | What it is | Current system? |
|---|---|---|
| **`CURRENT_SYSTEM\`** | Everything measured on our code as it is now, after the change: numbers, pictures, the real-page test. **Start with its README.md.** | **YES** |
| `INVESTIGATION_old_system_vs_DADE\` | How DADE sews lettering, and the OLD system against DADE, plus scratch experiments (DADE's own screens, the sheets sent to it, its 72 stitch files). | no (old system and DADE) |
| `older_runs_not_current\` | Earlier versions of the results, made at intermediate settings: the first dense version (too heavy, 1.55 times the drawn weight), runs at 0.25 mm row spacing, a build from before the last wording change. Kept for the record, superseded by CURRENT_SYSTEM. | no |
| `harness\` | The scripts that made all of it (they assume the session's scratch folder layout). | tools |

The change in one line: small lettering is now sewn as a plain fill with rows 0.2 mm apart (the way DADE sews it; our old small-piece rule stopped the rows short of the edge and erased the thin strokes), and the rows are laid in the letter taken in a little where it is thick, so the stitched letters weigh what the drawing weighs (1.22 times the drawn ink at 3 to 6 mm, where the first version of the fill was 1.55 times and DADE is 1.69). Characters wrong on nine fonts, caps 3 to 6 mm: 0.098 before, **0.018** now, DADE 0.068; on eighteen other fonts 0.125 before, **0.043** now, DADE 0.069.

Nothing was sewn on cloth: the pictures are stitch files drawn by our own routine and the numbers come from a text reader.
